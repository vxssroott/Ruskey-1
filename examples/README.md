# Examples

This directory contains small, self-contained Monkey language examples you can use to try out Ruskey. Since Ruskey currently exposes a REPL and library components, you can run these examples in one of two ways:

1. Start the REPL and paste the example contents into the interactive prompt.
2. If you add a small runner binary that accepts a filename and executes Monkey source through the interpreter, use that runner to run the files (not included in this repo yet).

Included examples

- fibonacci.monkey — computes fibonacci(10) using a recursive function.
- hello.monkey — simple string and variable usage.
- data_structures.monkey — demonstrates arrays and hashes.

Feel free to add more programs here as examples of language features.
